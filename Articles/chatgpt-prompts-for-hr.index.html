BEFORE YOU START

Three ingredients make a prompt far more useful

The article says better-quality output comes from three input elements: objective, context, and format. It uses a simple shopping-list example to show how adding context and structure improves the answer. :contentReference[oaicite:6]{index=6}

1

Objective

Tell the chatbot exactly what task to complete. Example: create, draft, list, summarize, compare, or analyze.

2

Context

Add the role, company type, industry, audience, location, constraints, or specific focus so the result is more relevant.

3

Format

Ask for the output style you want, such as bullet points, steps, checklist, email, survey, or comparison table.

TIP

Good prompt habits

  • Be as specific as possible
  • Build on the first answer with follow-up instructions
  • Use prompt chaining for better results
  • Break large requests into smaller parts when needed
CHECK

What makes a weak prompt

  • Too little context
  • No indication of audience or goal
  • No format instructions
  • Generic wording that invites generic output
BETTER PROMPTING

How to improve a basic HR prompt

The article uses an interview-question example to show how a basic prompt can be improved by specifying interview type, interviewer, job description, skills to test, and company or industry context. :contentReference[oaicite:7]{index=7}

BASIC VERSION

Generic example

Draft 10 interview questions for a candidate for the role of [role title] at [company name].
Usable, but still vague
IMPROVED VERSION

Stronger example

Draft 10 screening interview questions for a recruiter hiring a senior customer success manager in a B2B SaaS company. Focus on stakeholder management, renewals, and leading remote teams. Present the output in bullet points.
More context = more useful output

SAFE AND SMART USE

Guardrails HR should keep in place

The article repeatedly warns that the model can still produce incorrect or nonsensical output, does not truly understand what it generates, and should never be fed personal or confidential information casually. :contentReference[oaicite:9]{index=9}

GUARDRAIL 1

Always review the output

Check accuracy, completeness, legal wording, and brand fit before using any draft in HR practice.

GUARDRAIL 2

Do not enter confidential information

Keep employee, candidate, or company-sensitive data out of prompts unless your data controls are explicit and appropriate.

GUARDRAIL 3

Use prompt chaining

Start broad, then refine through follow-up prompts instead of trying to force a perfect first answer.

GUARDRAIL 4

Break complex tasks down

Large or multi-part requests often improve when separated into smaller, more manageable prompts.

GUARDRAIL 5

Experiment deliberately

Prompt engineering improves with practice, so test phrasing, tone, and structure to learn what works best.

GUARDRAIL 6

Use it as a productivity layer

ChatGPT is strongest as a support tool for drafting, brainstorming, and structuring work — not as a substitute for HR judgment.

What to avoid

  • Generic prompts with little context
  • Unreviewed AI text going straight into HR operations
  • Entering personal or confidential data into prompts
  • Assuming the first answer is always accurate

What to aim for

  • Clear objective, context, and format
  • Iterative prompting and refinement
  • Human review before practical use
  • Thoughtful use across the employee life cycle
